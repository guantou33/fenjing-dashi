1 · 连接 仓库已自动填好，平时不用管

目标仓库/分支已自动填好，不用你建仓库、也不用选仓库。第一次只需要粘一次 GitHub token（只存在你这台设备的浏览器里，不会发给任何人），以后就直接拖文件。

怎么拿 token：GitHub 头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → 只勾选 fenjing-dashi 这一个仓库 → Repository permissions 里把 Contents 设成 Read and write → 生成后复制（github_pat_…）粘到上面。 别用带 delete_repo 之类全权限的旧式 token，也别把这个页面链接连 token 一起发给别人。
